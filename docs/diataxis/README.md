# Diátaxis documentation for Personal Learning Assistant

This folder organizes the repository documentation by purpose:

- Tutorials help a new contributor learn the app by doing.
- How-to guides solve concrete tasks.
- Reference pages describe commands, structures, and data exactly.
- Explanation pages describe how the system fits together and why it is built that way.

## Start here

- [Tutorials](./tutorials/)
- [How-to guides](./how-to/)
- [Reference](./reference/)
- [Explanation](./explanation/)

## What this documentation covers

- Local-first study workflows for exams, quizzes, flashcards, and summaries
- The React + TypeScript + Vite application structure
- IndexedDB persistence and imported file validation
- Android packaging through Capacitor
- Test and build workflows used in this repository
